# kde-lyrics v0.1.0

第一个可用版本：面板显示实时歌词，弹窗查看封面、滚动歌词与播放控制。

## 新增

- Plasma 6 面板小组件，菜单栏显示当前歌词，可选单行 / 双行，超长自动跑马灯滚动
- 弹窗：封面、歌名 / 艺术家 / 专辑、上下文歌词、可拖动进度条、上一首 / 播放暂停 / 下一首
- 点歌词行直接跳到该句，拖动进度条松手才跳转
- 歌词来源三级：MPRIS `xesam:asText` → 本地 `.lrc` → LRCLIB，可在配置里分别开关
- 播放器只给纯文本时继续查找带时间轴的版本，拿到后无缝替换
- LRC 解析支持一行多时间戳、`[offset:]`、逐字标签；带时长与专辑的匹配评分
- 歌词与封面本地缓存（`~/.cache/kde-lyrics/`），切歌来回切不重复联网
- 多播放器自动选择（正在播放 > 暂停 > 有曲目，带专辑信息优先，正在显示的播放器不会被抢走），也可在配置里固定
- 全部颜色跟随 Kirigami 主题与强调色，明暗切换即时生效

## 已知限制

- 不支持逐字（卡拉 OK）同步
- 少数播放器 `Position` 恒为 0，进度靠本地推算，长播可能轻微漂移
- 浏览器网页播放器通常没有艺术家/专辑信息，歌词会走模糊搜索

## 升级 / 安装

```bash
git clone https://github.com/haoyn231/kde-lyrics.git
cd kde-lyrics
./install.sh --restart
```
