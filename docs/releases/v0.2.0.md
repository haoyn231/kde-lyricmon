# kde-lyrics v0.2.0

弹窗多了一种「播放器」布局，面板前面的音符图标可以单独关掉。

## 新增

- **弹窗布局可选**（设置 → 弹窗与播放器 → 弹窗布局）：
  - **经典**：和之前一样，信息在上、歌词在中、进度与控制在下
  - **播放器**：封面放大到左侧，歌名 / 艺术家 / 专辑压在封面底部（带渐隐，任何封面都能读），
    进度条与上一首 / 播放暂停 / 下一首排在封面下方，右侧是滚动歌词；弹窗同时变宽，
    高度略降
- 面板音乐图标开关：设置 → 面板 → 显示音符图标。关掉后菜单栏只剩歌词文字，
  留给歌词的宽度也自动变宽

## 改进

- 歌词列表在弹窗高度变化、或在两种布局之间切换后会重新把当前句居中
- 歌词区上下留白加大，滚动时边缘那半行不会紧贴着分隔线和进度条被硬切
- 文档截图改为全部由 `tools/render-preview.sh` 离屏渲染，可随时复现；
  2 倍图改用真正的 `QT_SCALE_FACTOR` 高 DPI 渲染，不再是把 1 倍图放大

## 说明

- 升级：`./install.sh --restart`（C++ 插件有改动，需要重新编译）
- 新增的配置项默认是「经典」布局、图标显示，升级后外观与 0.1.0 一致
