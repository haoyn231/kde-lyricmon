# kde-lyricmon v0.2.2

修掉刚开机、还没有音乐在放时，面板上的「未在播放」挤到隔壁组件图标上的问题。

## 修复

- 面板上的紧凑形态不再按子布局量出来的宽度分格子。Plasma 在组件构造期就会问
  `implicitWidth`，那会儿子布局还没 polish，量到的是 0，宽度退化成两倍
  `smallSpacing`（8px）。面板照着这个数分格子，而文字是居中摆放、父项又不裁剪的，
  于是向两边各溢出一截，压到旁边组件的图标上
- 宽度和高度改为用 `FontMetrics` 同步量出来（字体由 `Qt.font` 自己构造），
  构造期第一次求值就是正确值；不再依赖子项 polish 之后的尺寸
- 给根项补了 `clip`：万一面板给的格子仍然比内容窄，宁可裁掉也不会画到隔壁去
- 另外顺手修正竖向面板下宽度多算了一段 `spacing` 的问题

这个问题只在空闲态明显：没有播放时宽度算错后再没有任何东西触发重排，
一开播放器、文字变了，面板才重排回正常 —— 所以看起来像是「开播放器就好了」。

## 说明

- 升级：`./install.sh --restart`（本次只有 QML 改动，不需要重新编译也可以，
  覆盖后重启 plasmashell 即可生效）
- 已有配置无需迁移；歌词缓存格式没有变化
