# kde-lyricmon v0.2.1

同时放音乐和看浏览器视频时，面板只跟音乐播放器走；浏览器默认被忽略。

## 修复

- 浏览器（Chromium / Chrome / Firefox / Brave / Vivaldi / Edge / Opera 以及
  Plasma 浏览器集成）注册的 MPRIS 实例默认不再参与选主。看视频不会再抢走
  歌词面板，也不会出现在「固定播放器」列表里
- 修复浏览器集成把 `xesam:album` 填成网站 URL 后，在「带专辑信息优先」规则里
  压过真正音乐播放器的问题
- Chromium 系独立应用（Electron 等，例如 QQ）虽然共用
  `org.mpris.MediaPlayer2.chromium.instanceN` 服务名，但会按 `Identity` 识别，
  不会被误判成浏览器

## 新增

- 设置 → 弹窗与播放器 → 「忽略浏览器里的网页播放器（推荐）」，默认勾选；
  需要网页音乐也显示歌词时可以取消
- 浏览器识别单元测试，CI 一并运行

## 说明

- 升级：`./install.sh --restart`（C++ 插件有改动，需要重新编译）
- 已有配置无需迁移；`ignoreBrowsers` 默认即为开启
